# Food Delivery App

A food delivery mobile application built using React Native and Expo.

## Features 

- Food listing

- Food categories

- Food details

- Add food to cart

- Place orders

- API integration

- Navigation between screens

- Dynamic food data

- Responsive UI


## Tech Stack

- React Native

- Expo

- JavaScript

- React Navigation

- FlatList

- REST API

- Git & GitHub


## Project Structure

- app - Application screens

- components - Reusable components

- constants - App constants and data

- hooks - Custom hooks

- assets - Images and other assets


# Run the Project

### Clone the repository:

git clone https://github.com/sahil7494864/FoodDelivery.git

### Install dependencies:

npm install

### Start the project:

npx expo start

## About

I built this project to practice React Native development, API integration, navigation, and working with dynamic data.
